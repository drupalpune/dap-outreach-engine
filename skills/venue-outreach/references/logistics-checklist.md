# Logistics checklist

Goes into touch 4 (confirmation) and gets reconfirmed at T-10.

## Confirm with the host at T-30

- [ ] Date and time locked: third Saturday, 09:30–13:30
- [ ] Room and floor, with a landmark for the directions post
- [ ] Seating for 20–30
- [ ] Projector / screen, and which cable (HDMI? adapter needed?)
- [ ] Mic — needed above ~25 people in a hard-walled room
- [ ] Wi-Fi: guest network name and how passwords get handed out
- [ ] Weekend building access: is a name list needed, and by when?
- [ ] Security desk process — ID required? Visitor register?
- [ ] Parking, and whether two-wheelers are handled differently
- [ ] Tea/coffee/snacks: host providing, or DAP arranging?
- [ ] On-site contact name and mobile number for the day
- [ ] Host logo file for the announcement post
- [ ] Anyone from the host team who wants a slide or two at the start

## Reconfirm at T-10

- [ ] Final headcount to the host (RSVP count, and note that turnout runs lower)
- [ ] Name list submitted if required
- [ ] AV tested, or a 15-minute window before 09:30 to test it
- [ ] Directions confirmed and written for the reminder post
- [ ] Host contact reachable on the day
- [ ] Photos: is photography fine in the space?

## Day-of, T

- [ ] Arrive 45 minutes early
- [ ] AV test with the actual laptops
- [ ] Name tags, marker, and a spare HDMI adapter
- [ ] Thank the host from the front of the room, by name
- [ ] Group photo before people leave
- [ ] Room left as found; nothing on the whiteboard

## T+2

- [ ] Thank-you mail to the host and the on-site contact
- [ ] Recap post tagging the host org
- [ ] Row appended to `data/meetups.csv`
- [ ] Ask, once, whether they would host again in six months
